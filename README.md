# TASK 1: Language Translation Tool

## Features
- Source & target language selection (15+ languages)
- Auto-detect source language
- Free translation via MyMemory API (no API key needed for light use)
- Copy to clipboard button
- Text-to-Speech (browser TTS)
- Swap languages button
- Modern dark UI
- Keyboard shortcut: Ctrl+Enter to translate

## How to run
1. Open `translator.html` in any modern browser (Chrome, Edge, Firefox, etc.)
2. Type or paste text
3. Select languages
4. Click **Translate**

## Optional Python version
A simple console version is also provided in the main project notes if needed.

## Notes
- MyMemory has a daily free quota. For production use Google Cloud Translation, Azure Translator, or DeepL.
